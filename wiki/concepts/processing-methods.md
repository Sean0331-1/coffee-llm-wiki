# 處理法（Processing）

**定義**：咖啡豆其實是咖啡果實（coffee cherry，一種紅色的小果實）裡的種子。處理法指果實採收後，用什麼方式把種子取出、乾燥（來源：[Seattle Coffee Gear 豆袋指南](../sources/seattle-read-coffee-bag.md)）。

## 重點

- 處理法是影響咖啡風味最大的因素之一（來源：[Seattle Coffee Gear 豆袋指南](../sources/seattle-read-coffee-bag.md)）。
- 最常見的三種（來源：[Seattle Coffee Gear 豆袋指南](../sources/seattle-read-coffee-bag.md)）：

| 處理法 | 風味傾向 |
|---|---|
| 水洗（Washed） | 乾淨、明亮，最能喝出[產區](origin.md)本身的特色 |
| 日曬（Natural） | 連著果實一起乾燥，口感（body，喝起來的厚薄、重量感）較厚，果味明顯 |
| 蜜處理（Honey） | 介於兩者之間：有甜感和果味，但比日曬更有結構 |

- 另有實驗性的處理法，例如厭氧（anaerobic）處理：在密封、沒有氧氣的環境中發酵，可能產生特別狂野或複雜的風味（來源：[Seattle Coffee Gear 豆袋指南](../sources/seattle-read-coffee-bag.md)）。
- 對初學者來說，處理法和產區是讀標籤時最該先看的兩個欄位（來源：[Seattle Coffee Gear 豆袋指南](../sources/seattle-read-coffee-bag.md)）。
