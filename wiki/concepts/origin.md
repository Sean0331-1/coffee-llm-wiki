# 產區（Origin）

**定義**：咖啡種在哪裡。豆袋上可以只寫國家，也可以細到國內產區、農場、合作社或水洗站（來源：[Seattle Coffee Gear 豆袋指南](../sources/seattle-read-coffee-bag.md)）。

## 重點

- 標示的層級由粗到細：國家（例如 Ethiopia 衣索比亞）→ 國內產區（例如 Yirgacheffe 耶加雪菲）→ 合作社（cooperative，多位小農一起處理與販售咖啡的組織）或農場 → 水洗站（wash station，集中處理咖啡果實的場所）（來源：[Seattle Coffee Gear 豆袋指南](../sources/seattle-read-coffee-bag.md)）。
- 寫得越細，越能追溯（traceable）這包豆子的來歷（來源：[Seattle Coffee Gear 豆袋指南](../sources/seattle-read-coffee-bag.md)）。
- 單一產區（single origin，整包豆子來自同一個地方，而不是多地混合）的豆袋上，產區通常是最醒目的資訊（來源：[Seattle Coffee Gear 豆袋指南](../sources/seattle-read-coffee-bag.md)）。
- 產區能讓你預期大概的風味，但只是起點、不是規則（來源：[Seattle Coffee Gear 豆袋指南](../sources/seattle-read-coffee-bag.md)）：
  - 衣索比亞：常有花香與核果（stone fruit，桃子、杏桃這類有硬核的水果）風味。
  - 哥倫比亞：偏均衡、甜。
  - 肯亞：偏明亮（酸質鮮明）、帶有像葡萄酒的感覺。
- 對初學者來說，產區和[處理法](processing-methods.md)是最該先看的兩個欄位（來源：[Seattle Coffee Gear 豆袋指南](../sources/seattle-read-coffee-bag.md)）。
