# 豆袋標籤怎麼讀

**定義**：精品咖啡的豆袋（coffee bag）標籤，把這包豆子「從哪裡來、怎麼處理、什麼時候烘、大概什麼味道」濃縮在一小塊貼紙上。看懂它，就能在買豆或點單品咖啡前先猜到風味方向。

## 重點

- 標籤上的資訊看起來很多，但每一項都有用意；學會讀標籤，能幫你挑到自己真的會喜歡的咖啡（來源：[Seattle Coffee Gear 豆袋指南](../sources/seattle-read-coffee-bag.md)）。
- 常見欄位有八個：產區、品種、處理法、海拔、風味描述、烘焙日期、烘焙度、生產者資訊（來源：[Seattle Coffee Gear 豆袋指南](../sources/seattle-read-coffee-bag.md)）。
- 初學者的閱讀順序：先看產區和處理法，品種等喝過幾支、知道自己喜好後再研究（來源：[Seattle Coffee Gear 豆袋指南](../sources/seattle-read-coffee-bag.md)）。
- 烘焙日期被認為可能是袋上最重要的數字，因為它決定豆子新不新鮮（來源：[Seattle Coffee Gear 豆袋指南](../sources/seattle-read-coffee-bag.md)）。
- 生產者資訊（Producer Info）指農場、農民、合作社或水洗站的名稱；烘焙商揭露得越多，越能讓人對品質與生產條件有信心，這也是精品咖啡和大宗商品咖啡（commodity coffee）的差別之一（來源：[Seattle Coffee Gear 豆袋指南](../sources/seattle-read-coffee-bag.md)）。

## 各欄位速查

| 欄位 | 告訴你什麼 | 概念頁 |
|---|---|---|
| 產區 Origin | 種在哪裡，越細越可追溯，也暗示風味傾向 | [產區](origin.md) |
| 處理法 Processing | 果實採收後怎麼處理，影響風味最大的因素之一 | [處理法](processing-methods.md) |
| 海拔 Elevation | 種多高，高海拔通常風味較複雜 | [海拔](altitude.md) |
| 品種 Variety | 咖啡樹的品種，像葡萄品種之於葡萄酒 | [品種](variety.md) |
| 風味描述 Tasting Notes | 烘焙師喝到的味道印象，不是添加物 | [風味描述](tasting-notes.md) |
| 烘焙日期 Roast Date | 什麼時候烘的，決定新鮮度 | [烘焙日期與新鮮度](roast-date.md) |
| 烘焙度 Roast Level | 烘得多淺或多深 | [烘焙度](roast-level.md) |
| 生產者資訊 Producer Info | 誰種的、在哪處理 | （併在本頁） |
